## 3. PHM 학습 파이프라인 고도화

### 모델 입력 변환 모듈 추가

파일:

- `ai-server/training/phm_model_input.py`

역할:

- rolling feature가 준비된 행을 학습 가능한 `X`, `y`, `featureNames` 구조로 변환
- `deviceId`, `sampledAt` 식별자도 함께 보존
- 라벨은 `failureWithinHorizon`을 사용

핵심 feature:


## 8. 면접 설명 포인트

- rule baseline으로 운영 API 계약을 먼저 고정했다.
- 장비 상태 이력에는 모델 버전, feature별 위험 기여도, threshold 위반 근거, 권장 조치를 저장한다.
- 실제 학습 단계에서는 시계열 특성을 고려해 random split 대신 time-aware split을 사용했다.
- rolling feature는 현재 행을 제외한 과거 데이터만 사용해 데이터 누수 위험을 줄였다.
- ML baseline은 운영 API 교체 전 단계로 artifact와 평가 리포트를 생성하는 파이프라인으로 구성했다.
